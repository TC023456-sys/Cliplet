# Cliplet 1.0.7

发布当前本机已安装的 1.0.7 源码对应的 Apple Silicon / Intel 通用安装包。

- Cliplet 独立品牌、菜单栏图标、自有 GitHub 更新入口，保留 Maccy 作者署名和 MIT 许可证。
- 整合历史观察回调弱引用、孤立内容清理、缩略图与面板缓存生命周期修复。
- 包含纯文本粘贴、原输入框选区书签、辅助功能状态检查及不含剪贴板正文的状态日志。
- 非沙盒桌面版；升级时复用原有历史数据库和设置。自动粘贴需 macOS 辅助功能授权。

## 已知问题

微信中按快捷键呼出历史面板仍可能丢失原选区，点击历史后插入光标处而非替换选区。1.0.7 不宣称修复此问题；后续非激活面板修复候选版未包含在本次发布中。

## 安装与源码

下载 `Cliplet-1.0.7.zip`，将 Cliplet.app 放入“应用程序”。`Cliplet-1.0.7-Source.zip` 是对应完整源码，`SHA256SUMS.txt` 提供校验值。此包使用临时签名，未经过 Developer ID 签名或苹果公证；更新可能需要重新关联辅助功能授权。

发布流程执行数据迁移、选区和更新逻辑检查、上游单元测试、通用构建及严格签名核验。自动化测试不代表所有第三方软件均已实测。
